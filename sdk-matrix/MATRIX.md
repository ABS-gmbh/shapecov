# Cross-SDK defect matrix

Generated by `sdk-matrix/matrix.py`; do not edit by hand. Each defect class below was found or reported in one SDK. The matrix shows whether the others have it. A cell comes from a run of this script, or from the source it names; otherwise it says "not tested". **Bold** marks a defect that is present.

Codec faults ran on one release of each decoder, named in the table's header. The SDK behaviour checks ran on every js-stellar-sdk release from 16.3.0 to 17.4.0 that the pinned-SDK checks install, and on py-stellar-base 17.0.1.

## XDR codec faults

Every faulty case of that kind the generator made, run through each decoder. A case whose type a decoder does not have is not counted, so the totals differ. stellar-core's column comes from its recorded run, for the types its `print-xdr` command can decode. RFC 4506 says a decoder must reject each of these; stellar-core rejects all of them except the bool word, which it reads as true.
